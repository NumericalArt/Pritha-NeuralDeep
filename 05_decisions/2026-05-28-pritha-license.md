# Decision: Pritha License

Date: 2026-05-28
Status: accepted

## Decision

Pritha v0.1 uses the MIT License.

## Rationale

MIT is short, widely understood and low-friction for a lightweight developer tool. It fits the current goal: make the repository forkable, inspectable and easy to adapt.

## Consequences

- Add `LICENSE` with MIT text.
- Mention MIT in `README.md`.
- Revisit licensing only if future dependencies, hosted services or commercial distribution requirements make MIT insufficient.

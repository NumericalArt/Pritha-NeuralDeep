# Knowledge shipped with this distribution

Curated Markdown, templates and reusable reference implementations are included.
Raw intake (`00_inbox/`, `01_sources/notes/`, `01_sources/signals/`, `12_marketing/`)
is instance-local: it is indexed on the machine that collected it and never published.
Generated indexes are rebuilt locally. Task Chat, Voice transcripts, instance
registries, credentials and runtime archives are excluded. Historical child-agent
records were reduced to de-identified engineering sections; they never create cards.
Only Brief Desk ND is installed by bootstrap. Live agents belong to instance state.

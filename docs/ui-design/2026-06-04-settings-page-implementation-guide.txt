Implementation Guide: /settings page

Использовать уже заданные общие tokens, sidebar, typography, glass panels, status strip и button styles. Ниже — только специфика страницы Settings.

1. Route and purpose

Route: /settings
Desktop nav active item: Settings
Page title: Settings
Subtitle: Configure Pritha to work the way you want.

Страница — compact settings surface. Не превращать её в admin panel. Показывать только ключевые настройки и честные статусы возможностей.

11. Settings data model

export type CapabilityStatus =
  | "ready"
  | "disabled"
  | "manual_only"
  | "planned"
  | "not_installed"
  | "unavailable"
  | "pending_auth"
  | "failed";
export type SettingsState = {
  language: "en" | "ru";
  theme: "dark" | "system" | "light";
  accessMode: "localhost" | "lan" | "tailscale" | "qr";
  snapshotRetention: 1 | 2 | 3;
  summary: {
    version: string;
    status: CapabilityStatus;
    uptime: string;
    memoryIndex: "up_to_date" | "stale" | "failed" | "unknown";
    lastSelfTest: string;
  };
  limits: {
    codexLimits: CapabilityStatus;
    apiUsage: CapabilityStatus;
    budgetUsedPercent?: number;
  };
  proactivity: {
    status: "off" | "manual" | "planned";
    cronAdapter: CapabilityStatus;
  };
};

12. Interactions

One-click safe

switch language
select visible tab
open limits tab
open voice QR panel

Confirmation-required

Run Self-test
Clear Cache
Change retention if it deletes snapshots
Connect LAN/Tailscale beyond localhost
Run Manual Check if it writes report

Disabled/planned

Enable cron
Codex limits telemetry
Light theme, if not implemented
Tailscale, if not configured

13. Responsive behavior

Tablet

Right rail moves below main settings.

@media (max-width: 1279px) {
  .settings-layout {
    grid-template-columns: 1fr;
  }
  .settings-rail {
    display: grid;
    grid-template-columns: repeat(3, minmax(0, 1fr));
  }
}

Mobile

* no desktop sidebar;
* bottom nav;
* /settings opens compact settings;
* tabs become horizontal scroll;
* access cards become 2×2 grid or single-column;
* right rail cards move below General sections;
* hide excessive summary rows if needed.

Implementation Guide: /dev page

Использовать общие tokens, sidebar, typography, glass panels, status strip и navigation из предыдущих страниц. Ниже — только специфика страницы Developer (Read-only).

1. Route and purpose

Route: /dev
Desktop nav active item: Dev (Read-only)
Page title: Developer (Read-only)
Subtitle: Diagnostics and internal state for advanced users.

Страница предназначена для диагностики, а не для управления. В v1 она read-only: показывает внутреннее состояние, registry, scans, logs, reports, warnings, но не выполняет destructive/admin actions.

10. Data model

export type DevCapabilityStatus =
  | "ready"
  | "not_installed"
  | "none"
  | "failed"
  | "unknown";
export type DevModule = {
  id: string;
  label: string;
  status: DevCapabilityStatus;
  icon: string;
};
export type RegistryRow = {
  id: string;
  agent: string;
  version: string;
  mission: string;
  interface: string;
  deployment: string;
  status: "alive" | "missing" | "unknown" | "needs_check";
  updated: string;
};
export type FolderScanRow = {
  path: string;
  status: "ok" | "not_found" | "manifest_issue" | "ignored";
  updated?: string;
};
export type LogLine = {
  time: string;
  level: "INFO" | "WARN" | "ERROR";
  message: string;
};
export type LatestReport = {
  path: string;
  title: string;
  updated: string;
  type: "self_test" | "evolution" | "audit" | "recovery" | "registry";
};

11. Read-only action policy

Allowed:

View Raw
Details
Copy Info
Copy command
Copy JSON
Open in Codex
Open safe local folder
Open read-only report preview
Client-side log filtering

Not allowed in /dev v1:

Run Self-test directly
Clear actual logs
Clear cache
Repair manifest
Rescan if it writes cache/report
Start/stop services
Rebuild memory index
Edit registry
Delete anything
Install cron/launchd

If a visual button exists but action is not allowed:

disable it
or convert to Copy command / Open in Codex

Mobile

/dev is not part of primary mobile nav.

If opened manually:

* hide sidebar;
* show compact top nav;
* stack all panels;
* registry table becomes horizontal scroll;
* logs stay monospace with horizontal scroll;
* latest reports collapsible.

13. Visual checklist

Verify against reference:

* active sidebar item is Dev (Read-only);
* page title says Developer (Read-only);
* readiness panel is the first and widest block;
* module row has 8 compact module items;
* registry table is the visual center;
* folder scan and logs are side-by-side;
* warnings panel spans bottom of main area;
* right rail order is Environment → Voice Diagnostics → Memory Index → Latest Reports;
* log block uses monospace;
* INFO/WARN/ERROR colors are distinct;
* all dangerous-looking actions are disabled, read-only, or converted to copy/open commands;
* no page element suggests that cron/proactivity is installed;
* no editing UI appears anywhere.

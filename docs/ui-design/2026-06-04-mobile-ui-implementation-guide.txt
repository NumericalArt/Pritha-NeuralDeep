Implementation Guide: Mobile UI

Использовать те же design tokens, цвета, glass panels, typography и components, что на desktop. Ниже — только мобильная специфика для экранов Voice и Agents.

1. Mobile app shell

На mobile не показывать desktop sidebar. Использовать:

Top header
Scrollable page content
Bottom navigation

Default behavior:

mobile / -> /voice
desktop / -> /agents

Bottom nav:

Voice | Agents | Settings

Dev не показывать в основной mobile navigation. Если нужен доступ — через Settings → Developer details.

<MobileShell>
  <MobileHeader />
  <main className="mobile-page">
    {children}
  </main>
  <MobileBottomNav />
</MobileShell>

14. Mobile visual checklist

Verify against reference:

* /voice opens first on phone;
* no desktop sidebar;
* header logo/title compact;
* three status chips under header on Voice;
* Voice orb/wave dominates first screen;
* Stop Listening button is wide and gradient;
* Mute/Cancel are two separate dark buttons;
* Context, Active Task, Decision, Quick Actions stack vertically;
* bottom nav stays fixed and glassy;
* /agents shows summary chips before cards;
* agent cards are single-column and spacious;
* missing card shows only Restore;
* Add New Agent is a dashed compact card;
* no right rail, no lineage graph, no developer tab on primary mobile nav;
* content never hides behind bottom nav.

Ниже — инструкция для coding agent по реализации первой страницы Agents в Pritha Control Center по референсу. Новое лого Pritha пока не внедрять: оставить аккуратный placeholder/slot, чтобы позже заменить asset без переработки layout.

Implementation Guide: Pritha Control Center / Agents Page

1. Scope

Реализовать первую страницу Control Center:

Route: /agents
Desktop default: / -> /agents
Page name: Child Agents

Цель — максимально точно повторить visual direction из референса:

* тёмный glassmorphism UI;
* мягкие неоновые акценты;
* карточки child agents;
* левый sidebar;
* верхний status strip;
* правый информационный rail;
* нижняя lineage-lite панель;
* минималистичные действия без перегруза.

Не реализовывать пока новое лого Pritha. Сделать отдельный компонент:

<PrithaLogoPlaceholder />

Позже он будет заменён на финальный logo asset.

3. Tech stack

Use:

Next.js
React
TypeScript
CSS variables or Tailwind with design tokens
lucide-react for base icons

Не использовать тяжёлый UI-kit. Дизайн должен выглядеть custom, а не как стандартная component library.

4. Global visual style

Overall feel

Страница должна выглядеть как локальная operator console:

* глубокий navy/black фон;
* мягкие границы;
* glass panels;
* тонкие неоновые обводки;
* приглушённый текст;
* акценты зелёный/фиолетовый/синий/оранжевый/красный;
* без чрезмерного свечения.

Base viewport

Референс сделан примерно под:

1536 × 1024

Desktop layout должен хорошо выглядеть от:

1280px width and above

20. State-to-UI rules

function getPrimaryAction(agent: AgentCardModel) {
  if (agent.state === "missing") return "restore";
  if (agent.state === "needs-check") return "check";
  if (agent.state === "alive" && agent.activity === "active") return "stop";
  if (agent.state === "alive") return "start";
  return "check";
}

URL buttons:

Show Open/Copy only if agent.state === "alive" and url exists.

Missing:

Only Restore action.
No Start.
No Stop.
No Open.
No Copy.

Needs check:

Only Check action.
No Start/Stop until manifest is valid.

22. Accessibility

Required:

* all buttons keyboard-focusable;
* icon-only buttons have aria-label;
* state is not color-only: include text Alive, Missing, Needs check;
* reduced motion support;
* text contrast acceptable on dark background;
* copy/open buttons with labels for screen readers.

Example:

<button aria-label={`Copy URL for ${agent.name}`}>
  <CopyIcon />
</button>

Reduced motion:

@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.001ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.001ms !important;
  }
}

# Agents

This directory stores TechScope Agents Mother artifacts.

- `contracts/`: agent project contracts created before scaffolding.
- `research/`: architecture validation reports created from contracts before scaffolding.
- `reports/`: scaffold reports created after project generation and tests.
- `reference-implementations/`: reusable inspected implementation packs that Pritha can copy into descendants when a contract selects the pattern.

Generated agent projects are created as sibling folders by default, not inside this directory.

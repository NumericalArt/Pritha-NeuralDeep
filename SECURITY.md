# Security

Pritha NeuralDeep is active-beta software for a trusted, single-user machine.
Its Control Center can operate local projects and credentials. Bind it to
localhost; trusted-device access through Tailscale is an explicit optional setup.
Do not expose it as a public multi-user service.

Treat links, files, source text and voice input as untrusted. Review agent
permissions and approved publications. Never commit credentials, private state,
chat history or generated databases. Model and search calls use NeuralDeep;
Telegram receives only a deliberately approved publication.

Report vulnerabilities privately through GitHub's private vulnerability reporting
if enabled. Do not post credentials or private logs in a public issue.
